## **Mudras:**
This project is a real-time 3D particle / geometry system built with Three.js. Mudras gestures are captured via the camera to control particle /geometry building, expansion, and contraction. Multiple particle shapes can be switched in real time, with a colour picker for adjusting the overall particle colour. The interaction is fully real-time move your hands, and the particles respond instantly.

Use Three.js to create a real-time interactive 3D particle system.

**Requirements:**
1. Detect hand open/close gestures via the camera to control particle scaling and expansion.
2. Build particles using Points and BufferGeometry.
3. Provide a Ul panel to switch particle shapes (Circle, Square, Sacred Geometry.).
4. Add a colour picker for real-time colour control.
5. Ensure smooth and responsive gesture interaction.
6. Keep the UI clean and modern, including a full screen button.
